# Pipeline Outputs & Analytical Diagnostics

This directory contains all artifacts generated by the **Customer Lifetime Value (CLV) Prediction Pipeline**, including model evaluation results, feature selection outputs, Explainable AI (XAI) visualizations, customer segmentation figures, and diagnostic plots. These outputs support the analysis, validation, and interpretation of the machine learning models developed in this project.

---

# Directory Structure

```text
outputs/
├── distributions/               # Distribution plots, outlier treatment, and feature visualizations
├── shap_dependence/             # SHAP dependence and interaction plots
├── *.csv                        # Model metrics, feature rankings, prediction results
├── *.txt                        # Pipeline execution logs and manifests
└── *.png                        # Model evaluation figures and analytical visualizations
```

---

# Summary Reports & Data Logs

| File | Description |
|------|-------------|
| **pipeline_results_manifest.txt** | Execution log generated during the complete pipeline run, recording model training progress and generated outputs. |
| **final_test_performance_summary.csv** | Final evaluation metrics (R², MAE, RMSE) for Linear Regression, Random Forest, and XGBoost on the unseen test dataset. |
| **model_performance_summary.csv** | Validation and cross-validation performance comparison of all candidate machine learning models. |
| **top_10_future_clv_targets.csv** | Top 10 customers with the highest predicted Customer Lifetime Value for business retention strategies. |
| **customer_clv_predictions_val.csv** | Validation dataset containing actual CLV values alongside model predictions. |
| **vif_before_filtering.csv** | Initial Variance Inflation Factor (VIF) scores before recursive multicollinearity removal. |
| **vif_after_filtering.csv** | Final VIF scores after feature elimination, ensuring all remaining predictors satisfy acceptable multicollinearity thresholds. |
| **vif_table.csv** | Complete recursive VIF elimination log showing removed variables and corresponding VIF values. |
| **mutual_information_scores.csv** | Mutual Information regression scores ranking non-linear relationships between predictors and the target variable. |
| **spearman_rankings.csv** | Spearman correlation coefficients measuring monotonic relationships between engineered features and future CLV. |
| **xgboost_builtin_importance.csv** | Native XGBoost Gain feature importance rankings. |
| **random_forest_permutation_importance.csv** | Permutation importance scores computed for the Random Forest model. |
| **xgboost_permutation_importance.csv** | Permutation importance scores computed for the XGBoost model. |

# Subdirectories

## distributions/

Contains exploratory data analysis and preprocessing visualizations, including:

- Feature distribution histograms
- Kernel Density Estimation (KDE) plots
- Boxplots
- Before-and-after Winsorization comparisons
- Log-transformation comparisons
- Target variable distribution plots

---

## shap_dependence/

Contains SHAP dependence plots generated for the most influential features, illustrating feature interactions and non-linear relationships learned by the XGBoost model.

Typical plots include:

- `engagement_adjusted_value`
- `avg_purchase_value`
- `loyalty_status`
- `promotion_usage`
- `income`
- Additional high-impact engineered features

---

# Purpose

The outputs contained in this directory provide:

- Quantitative evaluation of machine learning model performance.
- Feature selection diagnostics and multicollinearity analysis.
- Explainable AI (XAI) interpretations using SHAP and permutation importance.
- Customer segmentation analysis for business strategy development.
- Supporting visualizations used throughout the dissertation and presentation.

These artifacts improve the transparency, reproducibility, and interpretability of the Customer Lifetime Value prediction framework.
